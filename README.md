# 📊 Safaricom Stock Market Data Analysis

## About the Project

Welcome to my Data Science learning journey!

This repository documents my progress in learning Python for Data Science through a practical analysis of historical Safaricom PLC (SCOM) stock market data from the Nairobi Securities Exchange (NSE).

The project is part of my effort to develop practical skills in data manipulation, statistical analysis, exploratory data analysis (EDA), and data visualisation.

Rather than simply learning programming concepts theoretically, I am applying them to real-world financial data to understand how data can be transformed into meaningful insights.

## 🎯 Project Objectives

- Develop practical Python programming skills.
- Learn how to import, inspect, and manipulate datasets.
- Apply descriptive statistics to financial data.
- Understand stock price movements and historical trends.
- Develop data visualisation and analytical skills.
- Build a portfolio of practical Data Science projects.

## 📚 Learning Progress

### 1. Python Fundamentals
- Basic Python syntax and print statements.
- Importing external libraries.
- Working with variables and data structures.

### 2. Data Loading and Inspection
- Importing CSV files using Pandas.
- Reading datasets with `pd.read_csv()`.
- Inspecting records using `head()`.
- Understanding dataset dimensions using `shape`.
- Checking missing values using `isnull().sum()`.
- Examining data types and structure using `info()`.

### 3. Descriptive Statistical Analysis
- **Mean:** Calculating average stock prices.
- **Median:** Identifying the middle stock price.
- **Standard Deviation:** Measuring the variability of stock prices.

## 📈 Dataset

The project uses historical Safaricom PLC stock market data containing seven columns, including:

- Date
- Open
- High
- Low
- Close
- Volume
- Percentage Change

Initial dataset inspection identified 1,753 observations across seven columns.
